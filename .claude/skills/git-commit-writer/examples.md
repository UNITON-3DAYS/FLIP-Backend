# 실제 작성 예시 (few-shot)

이 프로젝트 커밋 이력에서 그대로 가져온 예시. 이 정도 밀도로 작성할 것.

## 커밋 메시지 스타일 (실제 이력, 제목+본문 전체)

제목만 있는 경우도 있지만, **대부분 제목 + 빈 줄 + 개조식 불릿 본문**이 기본형:

```
chore: GCP 인프라 및 배포 파이프라인 구성

- 신규 GCP 프로젝트 생성
- dev/prod 구분 없이 단일 prod 인스턴스(e2-medium)로 구성
- tfstate 백엔드를 별도 GCS 버킷으로 관리
- GitHub Actions(deploy-prod.yml)로 main push 시 Docker Hub 빌드/푸시 후 VM SSH 배포
```

사소한 변경(설정 하나 제거 등)은 제목 한 줄로 끝내기도 함:
```
chore: 불필요한 주석 제거
```

## 신선한 예시가 더 필요하면
이 파일이 오래됐다 싶으면 직접 최근 이력을 확인해서 참고할 것. **`--oneline`은 제목만 보여주고 본문을 숨기니 쓰지 말 것**:
```bash
git log -15 --format='%s%n%n%b%n---'
```
