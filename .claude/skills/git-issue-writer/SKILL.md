## 반드시 따를 템플릿/컨벤션
FLIP-Backend엔 `.github/ISSUE_TEMPLATE` 파일이 아직 없음 — 아래 섹션 구조를 그대로 사용 (섹션 새로 만들거나 빼지 않기):

```markdown
## 📝 개요
- (무엇을, 왜 — 1~2줄)

## ✅ To-Do
- [ ] (작업 항목)

## 👀 ETC
- (참고사항/배경/트레이드오프. 없으면 "(해당 없음)")
```

- 제목은 `<type>: <한 줄 요약>` (`feat`/`fix`/`perf`/`refactor`/`chore` 등, 커밋 컨벤션과 동일한 타입 사용)
- `gh issue create --repo UNITON-3DAYS/FLIP-Backend --title "..." --body "..."`로 생성

## 작성 톤 (중요)
- 각 섹션은 짧은 불릿 위주. 완전한 문장/서술형 문단 금지
- "~했습니다", "~할 예정입니다" 같은 서술형 어미 대신 명사형/개조식으로
- 왜(why)가 필요한 항목만 한 줄 설명 추가, 나머지는 항목만
- 해당 없는 섹션은 "(해당 없음)"으로 짧게 표시하고 섹션 자체는 지우지 않기

## 이슈 생성 전 확인
- 제목·본문 초안을 사용자에게 먼저 보여주고 컨펌 받은 뒤 `gh issue create` 실행할 것 (임의로 바로 생성하지 않기)
